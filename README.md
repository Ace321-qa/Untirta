# AKMI Untirta Website

Official website project for **AKMI Untirta** (Aktivitas Keagamaan Mahasiswa Islam Universitas Sultan Ageng Tirtayasa), a campus Islamic student activity unit at Universitas Sultan Ageng Tirtayasa.

This project is being built step by step. See the `docs/` folder for planning documents:

- [`docs/PROJECT-VISION.md`](docs/PROJECT-VISION.md) — organization profile and project charter
- [`docs/FEATURES.md`](docs/FEATURES.md) — feature backlog (MVP vs. later)
- [`docs/DECISIONS.md`](docs/DECISIONS.md) — decisions and assumptions log
- [`docs/PROGRESS.md`](docs/PROGRESS.md) — build progress tracker

No application code exists yet — the project is currently in Phase 0 (discovery and planning).
